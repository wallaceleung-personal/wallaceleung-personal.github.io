Privacy Policy

Last updated: 3 October 2026

google-mcp ("the app") is a personal tool run by Wallace Leung on his own computer, for use with his own Google accounts only.

Data the app accesses

With the account owner's consent, the app accesses Gmail, Google Drive, Google Docs, Google Sheets, Google Slides and Google Calendar data through Google APIs. It does this only when the owner asks it to perform a task, such as reading an email or creating a document.

How data is used and stored

  • The app runs locally on the owner's computer. It does not send Google user data to any server operated by the developer.
  • OAuth tokens are stored only on the owner's computer, and the owner can delete them at any time.
  • Google user data is not sold, not used for advertising, and not shared with third parties. The only exception is the AI assistant that the owner chooses to use with the app, which receives data only to carry out the owner's request.
  • No Google user data is used to develop, improve or train generalized AI or machine-learning models.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke the app's access at any time at myaccount.google.com/permissions.
